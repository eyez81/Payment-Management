# המנויים שלי

האפליקציה משתמשת ב־Google Apps Script שקשור לגיליון הפרטי שלך. קוד המקור נשמר בריפו הזה ב־GitHub. האפליקציה עצמה נפתחת בכתובת ש־Google תיתן לאחר הפריסה. אין צורך ב־Google Cloud, ב־OAuth Client ID או בהפיכת הגיליון לציבורי.

## התקנה

1. פתח את הגיליון המקורי ב־Google Sheets. הוא צריך להיות גיליון Google אמיתי ולא קובץ Excel שמוצג בתצוגת תאימות. שם הלשונית בתחתית צריך להיות `מנויים`, עם עשר העמודות שקיבלת בתבנית.
2. בתפריט הגיליון: **תוספים → Apps Script** (בממשק אנגלי: **Extensions → Apps Script**).
3. בעורך, פתח את `Code.gs`, מחק את הטקסט הקיים והדבק במקומו את כל תוכן [Code.gs](Code.gs) מהריפו הזה.
4. לחץ **+ → HTML**, תן לקובץ את השם `Index` והדבק בו את כל תוכן [Index.html](Index.html). שמור את שני הקבצים.
5. לחץ **Deploy → New deployment**. בחר סוג **Web app**. תחת **Execute as** בחר **Me**; תחת **Who has access** בחר **Only myself**. לחץ **Deploy** ואשר ל־Google את ההרשאה לגיליון שלך. אם חשבון Google Workspace שלך מציג שמות מעט שונים, בחר באפשרות שמאפשרת גישה רק לך.
6. העתק את ה־**Web app URL** שקיבלת ופתח אותו. זה הקישור לאפליקציה שלך, גם בטלפון.

אם ערכת את הקוד בעתיד, בצע **Deploy → Manage deployments → Edit → New version → Deploy**. שמירת הקובץ בלבד אינה מעדכנת פריסה קיימת.

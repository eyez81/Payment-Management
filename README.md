# ניהול מנויים ותשלומים

אפליקציה בעברית ל־GitHub Pages, שמציגה את המנויים וקוראת וכותבת ישירות בגיליון Google Sheets פרטי. היא מותאמת לגיליון שסוכם עם אייל, במזהה `1HuCg5keyzs4BQIa3ZjzEyEVB54j-SwtGarFP5uq48Pk`.

## הגיליון

שם הלשונית חייב להיות `מנויים`. שורה 1 צריכה להכיל את הכותרות האלה בסדר הזה:

| A | B | C | D | E | F | G | H | I | J |
|---|---|---|---|---|---|---|---|---|---|
| שם השירות | קטגוריה | סכום לתשלום | מטבע | תדירות | תאריך החיוב הבא | תאריך סיום | אמצעי תשלום | מצב | הערות |

המטבע הוא `שקל`, `דולר` או `אירו`; התדירות היא `חודשי`, `שנתי` או `חד פעמי`; המצב הוא `פעיל`, `מושהה` או `בוטל`. תאי התאריכים נשמרים כתאריכים מספריים ב־Sheets, והאפליקציה שומרת על פורמט התאריך של העמודות. השאר את הגיליון פרטי; אין צורך בשיתוף ציבורי.

## הגדרת גישה חד פעמית

אתר GitHub Pages הוא אתר סטטי, ולכן צריך OAuth Client ID כדי לקבל הרשאה לקריאה וכתיבה בגיליון הפרטי דרך הדפדפן. **Client ID אינו Client Secret**. אין לשים Client Secret בריפו.

1. ב־[Google Cloud Console](https://console.cloud.google.com/) צור פרויקט או בחר פרויקט קיים.
2. ב־**APIs & Services → Library** הפעל **Google Sheets API**.
3. ב־**Google Auth Platform → Branding / Audience** הגדר את מסך ההסכמה. בחשבון Gmail אישי בחר External. אם הפרויקט במצב Testing, הוסף את כתובת ה־Gmail שלך לרשימת Test users.
4. ב־**Data Access** הוסף את ההרשאה `https://www.googleapis.com/auth/spreadsheets`.
5. ב־**Clients** צור **OAuth client ID → Web application**. בשדה **Authorized JavaScript origins** הזן `https://eyez81.github.io` (ללא נתיב הריפו וללא לוכסן בסוף).
6. העתק את ה־Client ID שמסתיים ב־`.apps.googleusercontent.com` והדבק אותו באפליקציה. לחץ **שמירה וכניסה עם Google** ובחר את חשבון Google שמחזיק בגיליון.

Google עשויה לבקש אישור למסך ההסכמה או להציג אזהרה על אפליקציה שטרם אומתה. אל תכניס סיסמה או סוד לתוך האתר. ה־Client ID נשמר רק בדפדפן שלך; אסימון הגישה נשאר בזיכרון הדף עד לרענון. ההרשאה `spreadsheets` רחבה: היא מעניקה לאפליקציה גישה לגיליונות שהחשבון המחובר יכול לגשת אליהם, אבל הקוד הזה פונה רק למזהה הגיליון המצוין למעלה.

## שימוש

- אפשר להוסיף, לערוך ולמחוק מנוי. כל פעולה כותבת שורה אחת בלבד בגיליון; לפני עריכה או מחיקה האפליקציה בודקת שהשורה לא השתנתה מאז הטעינה.
- תאריך החיוב הבא הוא תאריך שתעדכן לאחר חיוב. האפליקציה אינה מקדמת אותו אוטומטית ואינה שולחת תזכורות בדוא״ל.
- העלויות החודשיות והשנתיות הן ממוצע המחושב ממנויים פעילים, בנפרד לכל מטבע. חיוב חד פעמי, מנוי מושהה, מבוטל או כזה שהסתיים אינם נכללים בסיכום.
- האפליקציה קוראת עד 999 שורות מידע. עריכת אותו גיליון במקביל ממכשירים שונים עלולה ליצור התנגשות; השתמש בכפתור רענון.
